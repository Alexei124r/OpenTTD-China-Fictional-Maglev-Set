# China Fictional Maglev Set

Version 0.1.2-alpha

Source and issue tracker:
<https://github.com/Alexei124r/OpenTTD-China-Fictional-Maglev-Set>

China Fictional Maglev Set is an unofficial, fictional maglev vehicle set for
OpenTTD. It includes TR08, TR2012, TR2015 passenger stock, TR2015F freight
stock, the MR2015 engineering and towing vehicle, and a TR2015 dining car.
Several liveries are selectable by refitting.

The set provides configurable passenger capacity, purchase and running costs,
mail capacity, loading speed, passenger comfort and freight freshness. MR2015
can isolate traction and limit a mixed consist to 100 km/h.

Install it through OpenTTD's online content service, or place
`china_fictional_maglev.grf` in the OpenTTD `newgrf` directory and enable it in
NewGRF Settings.

This is an unofficial fan-made set. It is not affiliated with or endorsed by
Shanghai Metro, Transrapid, ThyssenKrupp, or any railway operator.

## 中文简介

中国架空磁浮车辆包是面向 OpenTTD 的非官方架空磁浮车辆集合，包含 TR08、
TR2012、TR2015 客运车辆、TR2015F 货运车辆、MR2015 工程车和 TR2015 餐车。
车辆支持多种涂装、载客量/费用/装卸速度参数，以及客运舒适度和货运保鲜度。
